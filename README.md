# 🚀 AI Website Builder

An AI-powered website creation platform designed to help customers build websites quickly using **pre-designed templates**, with an option to upgrade to a **Premium AI Website Service**.

## 📌 Overview

This project provides a simple way for customers to create basic websites without needing technical or coding knowledge.

The platform offers a collection of **pre-created website templates** that customers can select and customize according to their requirements.

For customers who need a more advanced and personalized website, the platform also provides a **Premium Service**, where custom AI-powered websites can be developed along with an integrated AI chatbot.

---

## ✨ Features

### 🆓 Basic Website Builder

The basic version allows customers to:

* Choose from pre-created website templates
* Select a website design based on their needs
* Customize basic website content
* Create simple responsive websites
* Build websites without coding knowledge
* Preview their website before publishing

The Basic service focuses on **simple and affordable website creation** using existing templates.

> **Note:** AI chatbots are not included in the Basic service.
